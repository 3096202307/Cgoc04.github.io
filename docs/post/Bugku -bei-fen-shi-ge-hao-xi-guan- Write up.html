           index.php.bak      ← 备份

           .index.php.swp
           www.zip / www.tar.gz   ← 整站打包

分析源码，我们得到能够得到flag的条件

if(md5($key1) == md5($key2) && $key1 !== $key2){
echo $flag."取得flag";
}

拆成两个条件：

条件 运算符 含义 要求
md5($key1) == md5($key2) == 弱比较 只比值，会先转类型 两个哈希"相等"
$key1 !== $key2 !== 严格不等 类型和值都要一样才算等 两个原始串必须不同

两个都成立才给 flag。

于是我们想到了 PHP == 弱比较 —— "0e 魔术哈希"
