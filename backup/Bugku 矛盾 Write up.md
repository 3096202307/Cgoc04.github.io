打开题目所给靶机地址，源码直接呈现再当前页面上
$num=$_GET['num'];
if(!is_numeric($num))
{
    echo $num;
    if($num==1)
        echo 'flag{**********}';
}

一眼看上去，**两个条件自相矛盾**：

| 条件 | 要求 |
|:---|:---:|
| ① `!is_numeric($num)` | 这个值**不能是数字** |
| ② `$num == 1` | 这个值**必须等于一** |

**既要"不是数字"，又要"等于 1"** —— 正常思路走不通，说明这里有**类型转换的漏洞**。
**要同时满足，必须找一个"整体看起来不是数字、但开头解析出来是 1"的值。**

根据源码中出现`if(!is_numeric($num))`这一行代码，我们可以判断其用PHP语法编写

PHP 7 在**两个地方用了两套不同的标准**：

| 函数 / 运算符 | 判断标准 |
| --- | --- |
| `is_numeric()` | 要求**整个字符串**都是合法的数字格式 |
| `==`（与数字比较时） | 只**从开头解析**，碰到第一个非数字字符就停 |

也就是说：

    "1+任意英文字母（中间无空格）"
       │
       ├── is_numeric("1+任意英文字母")  →  false   ← 因为 'a' 不是数字，"整体"不合法
       │
       └── "1+任意英文字母" == 1         →  true    ← 因为开头解析出 1，1 == 1

**一个说"不是数字"，一个说"等于 1" —— 缝就在这里。**

于是我们在靶机地址后加上/?num=1a，回车，页面上出现flag，提交flag，flag正确，完活。
