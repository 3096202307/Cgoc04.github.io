## 重排
根据题目“黄道十二宫”及题目类型为Crypto以及附件所给图片的特征判断其加密方式为美国连环杀手“黄道十二宫”寄出Z340密码信所采用的换位密码加密方式。
知道加密方式后，要想解出密文背后的信息，我们先将密文进行重排，9 行 × 15 列，每次下移 1 行、右移 2 列，将重排后的密文按9 行 × 15 列的方式排列。
于是我们得到重排后的密文：

```

%%>%..@3*.#(#0+
@#+.@)8@7@*7@@1
#5&8=.*9@=)#6#7
>0#7%%8$+@-#5?*
13@?7-+(^(*==$$
1*=+#==^4~@)8%=
%=0.*&*.+8*1*1>
@#)8@76%=@%6%..
?#1(%15@(#>%...
```

## 解密
(用 AZdecrypt 破解)
将重排完的密文放进AZdecrypt里，加载好语言模型后进行解密。
解得：
```
IIKILLEDALOTOFP
EOPLETHEREAREEN
OUGHSLAVESTOWOR
KFORIIHOPEYOUCA
NDECRYPTITASSOO
NASPOSSIBLETHIS
ISFLAGALPHANANK
EOTHERWISEIWILL
CONTINUETOKILLL
```
## Flag
根据解码后所给的信息，我们发现第7行提供了这样一段文字：
```

is flag alaphanank
```
于是乎我们就得到了flag{alaphanank}，提交flag，flag正确，完活。

值得一提的是，**十二宫杀手**是 1960 年代美国的连环杀手，每次作案后给报社寄密码信。他最著名信件的是 Z408 和 Z340，其中 **Z340 直到 2020 年才被破解**（困扰了 51 年）。同时，本题所使用工具**AZdecrypt** 是一个用「爬山法 + 语言模型」自动求解古典密码的工具，作者 Jarl Van Eycke。**2020 年就是它破解了十二宫杀手的 340 密码。**
